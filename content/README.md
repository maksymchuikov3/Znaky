# Контент: формат пакета питань

Застосунок працює офлайн: питання поставляються у файлі
`core/data/src/main/assets/content/questions.json` і при першому запуску (або коли
`version` у файлі більша за збережену) завантажуються в локальну базу Room.
Прогрес користувача при оновленні контенту зберігається.

> ⚠️ Зараз у файлі — **26 зразкових питань, написаних нами** для розробки й тестів.
> Це не офіційна база. Перед релізом їх потрібно замінити на імпорт з відкритої бази ГСЦ МВС
> і звірити кожне посилання на пункт ПДР з чинною редакцією (zakon.rada.gov.ua).

## Схема

```jsonc
{
  "version": 1,                       // збільшувати при кожній зміні
  "rulesEdition": "…",                // редакція ПДР, показується користувачу
  "topics": [
    { "id": "tr-12", "number": "12", "title": "Швидкість руху", "block": "TRAFFIC_RULES" }
  ],
  "questions": [
    {
      "id": "q-0001",                 // стабільний; на нього посилається прогрес
      "topicId": "tr-12",
      "text": "…",
      "answers": [ { "id": "a", "text": "…" }, { "id": "b", "text": "…" } ],
      "correctAnswerId": "b",
      "image": "content/images/q-0001.webp",   // необов'язково, шлях в assets
      "ruleRefs": ["12.4"],           // пункти ПДР
      "explanation": "…",             // наше власне пояснення, необов'язково
      "categories": ["B", "BE"]       // категорії посвідчення
    }
  ]
}
```

`block` — один з: `TRAFFIC_RULES` (ПДР), `ROAD_SAFETY` (безпека руху), `VEHICLE` (будова ТЗ),
`FIRST_AID` (домедична допомога). Від блоку залежить розподіл 10/4/4/2 в іспиті.

## Правила

- Питання й ілюстрації — тільки з офіційних відкритих джерел. Тексти пояснень пишемо самі;
  не копіюємо пояснення, картинки чи формулювання з інших застосунків і сайтів.
- `id` питань не змінюються між версіями, інакше користувачі втратять прогрес.
- Валідатор (`ContentPackValidator`) запускається в юніт-тесті `BundledContentTest` у CI:
  дублікати, невідомі теми/категорії, відсутня правильна відповідь ламають збірку.
